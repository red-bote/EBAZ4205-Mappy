# EBAZ4205 - Mappy

Mappy Arcade verilog code ported to an EBAZ-4205 ZYNQ-7010 FPGA Board by PinballWiz.org 2026.  
Works with VGA Monitor. Code from Mister-X.

## Basys 3 port

Digilent Basys 3 version on branch `Port-to-Basys-3`, tested on hardware: see
[EBAZ4205-Mappy/basys3/README.md](EBAZ4205-Mappy/basys3/README.md).

The Basys 3 version does not change the core files. The EBAZ4205 project is unchanged.
